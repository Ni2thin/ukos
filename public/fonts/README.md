# UKOS typography

Satoshi (400, 500, 700) downloaded from the official Fontshare API and CDN:
https://www.fontshare.com/fonts/satoshi
Provider licensing terms: https://www.fontshare.com/licenses

Staatliches and Stint Ultra Condensed downloaded from Google Fonts.
Their SIL Open Font Licenses are included alongside the font files.

Fonts are served locally through next/font/local, with swap and fallbacks.
UI: Satoshi. Page and section headings: Staatliches. Decorative Home title: Stint Ultra Condensed.
